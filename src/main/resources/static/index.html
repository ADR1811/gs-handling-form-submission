Handling Form Submission

Démo d'un formulaire serveur : on affiche un form, on le soumet, on réaffiche les données liées à l'objet Greeting. Deux endpoints, une seule route.

Endpoints

GET /greeting

Affiche le formulaire vide. Le controller crée un Greeting neuf et le passe à la vue pour le binding Thymeleaf.

Méthode
greetingForm()
Vue
templates/greeting.html
Renvoie
Page HTML avec le champ id et content
Ouvrir le formulaire
POST /greeting

Reçoit les champs soumis. @ModelAttribute instancie un Greeting et le remplit via ses setters, puis on affiche le résultat.

Méthode
greetingSubmit()
Entrée
champs form id, content
Vue
templates/result.html

Déclenché en soumettant le formulaire ci-dessus (pas d'accès direct au navigateur).

Le flux

1. Le navigateur appelle GET /greeting → form vide rendu.
2. L'utilisateur remplit et soumet → POST /greeting.
3. Spring lie les champs à l'objet Greeting → rend result.html avec les valeurs.
